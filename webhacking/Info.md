# Web Hacking

## 💰 How to Make Money

### Bug Bounty
Find security vulnerabilities in authorized websites and report them.
**Example:** Finding an IDOR that lets one user access another user's profile.

### Penetration Testing
Test a company's systems with permission to find security weaknesses.
**Example:** Testing a company's web application for SQL injection.

---

# 🌐 Web Vulnerabilities

### SQL Injection
A vulnerability where user input can interfere with a database query.
**Learn:** SQL queries, input validation, parameterized queries.

### XSS
A vulnerability where attacker-controlled JavaScript executes in another user's browser.
**Learn:** HTML, JavaScript, input/output handling.

### CSRF
Tricks an authenticated user into sending an unwanted request.
**Learn:** Cookies, sessions, CSRF tokens.

### File Inclusion
A vulnerability where an application loads an unintended file.
**Learn:** File paths, server-side code, input validation.

### Authentication Bypass
Getting access without properly proving your identity.
**Learn:** Login systems, sessions, authentication logic.

### IDOR
Accessing another user's resource by changing an identifier.
**Example:**
`/user/1001` → `/user/1002`

**Learn:** Authorization and access control.

# 🧰 Tools

### Burp Suite
Intercept and modify HTTP requests.
**Use:** Web application testing.

### Nmap
Discover hosts, ports, and services.
**Use:** Network reconnaissance.

### SQLmap
Automate authorized SQL injection testing.
**Use:** SQL injection labs.

### Gobuster
Discover directories and other web resources.
**Use:** Content discovery.

### Nikto
Scan web servers for common security issues.
**Use:** Basic web server assessment.

### Browser Developer Tools
Inspect and debug web applications.
**Use:** HTML, JavaScript, cookies, storage, and HTTP requests.

# 🧠 Skills

### JavaScript
Understand how browser-side code works.
**Important:** DOM, Fetch, cookies, events.

### Linux Commands
Learn to work efficiently from the terminal.
**Important:** `grep`, `find`, `curl`, `cat`, `chmod`.

### Networking Basics
Understand how computers communicate.
**Important:** IP, ports, TCP, DNS, HTTP, HTTPS.

### HTTP Fundamentals
Understand how browsers communicate with servers.
**Important:** GET, POST, headers, cookies, sessions, status codes.
